# Pesquisa Culturama

Formulário de pesquisa de opinião desenvolvido em HTML e CSS, com validação nativa de campos e página de confirmação após o envio.

## Funcionalidades

- Formulário organizado em seções (dados pessoais, perfil, hábitos, opinião e confirmações)
- Validação de campos obrigatórios e de formato (e-mail, idade, telefone)
- Feedback visual de campos válidos/inválidos
- Layout responsivo e acessível
- Redirecionamento para página de sucesso após o envio

## Tecnologias

HTML5 · CSS


## Como executar

Clone o repositório e abra `index.html` no navegador. :rocket: :computer:
